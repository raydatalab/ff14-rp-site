# FF14 RP Staff Page

A static HTML page showcasing staff, group photos, posters, and menu for a FF14 RP shop.

## Structure

- `index.html` — main page
- `data/` — staff and menu data
- `images/` — all image assets
- `images/cards/` — full-resolution employee cards used in the detail modal
- `images/cards/thumbs/` — 480 × 225 WebP previews used by the lazy-loaded staff grid

## Card Specs

- **Image format**: WebP
- **Card dimensions**: 2076 × 974 px (landscape)
- **Display preference**: modal top-bottom layout for landscape images

## Usage

Open `index.html` in any browser.
